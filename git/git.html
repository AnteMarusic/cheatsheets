It's any expression that resolves to a commit. In detached HEAD state you are not on any branch — commits made here are temporary unless you create a branch from them. garbage collection HEAD~4 rev-operators - HEAD^ — first parent commit (navigation along history). - HEAD^{tree} — peel HEAD to its tree object (change of object type, same snapshot). @{...} — time / position / upstream selectors Looks things up in refs and the reflog — the history of where a ref has been, or its relationships. It's about which state of a ref, not object type. Local, time-based, can expire. HEAD@{2} # where HEAD was 2 moves ago (reflog) main@{yesterday} # where main pointed yesterday main@{upstream} # the upstream branch main tracks (also @{u}) HEAD@{push} # where main would push to @{-1} # the previously checked-out branch index git status git status -u # show status including untracked files git add git restore git commit git stash clean git rm -r --cached # --cached removes it from the index but not from the working tree.
