Git cheatsheet

Setup & Config

Basics

man git-<command>
help for a specific command, e.g. man git-rebase
man gitglossary
reference glossary of git terms (upstream, merge base, ...)
git init
create a repository in the current folder

Config

git config
get and set repository or global options
git config user.name <name>
set the author name
git config user.email <email>
set the author email
git config alias.<name> <cmd>
create a command alias
git config core.editor <editor>
set the default editor

.gitignore

*.log
any file ending in .log
build/
a directory named build
/secret.txt
secret.txt only in the repo root
doc/**/*.pdf
PDFs in doc/ at any depth
!important.log
negation: re-include a previously excluded file

Glossary

repository
a folder tracked by git; git runs locally storing data in .git
commit
a snapshot of the repository, identified by a hash
branch
a pointer to a commit
HEAD
pointer to the current position; points to a branch or a commit
ref
a name pointing to a commit (HEAD, branch, tag)
object
stored content: blob, tree, commit, tag
revision
an expression that resolves to a commit
detached HEAD
not on any branch; commits here are lost unless you branch
garbage collection
removal of unreachable objects

Ancestry operators

HEAD~4
4 commits back along first parents
HEAD^
first parent commit
HEAD^2
second parent (merge commit)

Revision operators

^{...} peel by type

HEAD^{tree}
peel HEAD to its tree object
HEAD^{commit}
peel to a commit
<tag>^{}
peel a tag until it is no longer a tag

@{...} selectors

HEAD@{2}
where HEAD was 2 moves ago (reflog)
main@{yesterday}
where main pointed yesterday
main@{upstream}
the upstream branch main tracks (also @{u})
HEAD@{push}
where the branch would push to
@{-1}
the previously checked-out branch

Ranges

A..X
commits reachable from X but not from A; empty when X is A or one of its ancestors

Working tree & Index

Status

git status
show the working tree status
git status -u
show status including untracked files

Stage & restore

git add
stage changes into the index
git restore
discard changes in the working tree
git commit
record the index as a new commit
git stash
save changes away and clean the working tree
git clean
remove untracked files

Untrack

git rm -r --cached <file>
stop tracking a file but keep it locally

Worktree

git worktree
a second checkout of the same repo in another directory, sharing .git; work on two branches at once

Commits & History

Inspect

git log [<options>] [<revision-range>] [-- <file-path>]
show commit history; revision-range defaults to HEAD, --all is all branches
git blame <file-path>
show revision and author that last modified each line
git show <object>
inspect an object
git ls-tree
list the content of a tree
git ls-files <file>
list the content of the index
git diff
show changes between working tree, index, trees, blobs, or files

Options

--oneline
one line per commit
--graph
draw the commit graph
--all
all branches
--decorate
show ref names
--stat
show changed files summary

Rewrite & undo

git revert
create a commit that undoes another
git reset
move the current branch (soft / mixed / hard)
git commit --amend
replace the last commit
git rebase -i
interactively reorder, squash, edit commits
git cherry-pick
apply a commit from elsewhere

Debug & recover

git bisect
binary search for a bad commit
git reflog
history of where HEAD and branches pointed

References

Tags

git tag <name>
lightweight tag (just a pointer)
git tag -a <name> -m <msg>
annotated tag (object with author, date, message)
git push <remote> <tag>
push a tag (not pushed by default)
git push --tags
push all tags

Branches

git branch
list branches
git branch -d <branch>
delete a branch (only if merged)
git branch -D <branch>
force-delete a branch (even if not merged)
git branch -m <old> <new>
rename a branch
git branch -f <branch> <commit>
force a branch to a commit without checkout
git switch / git checkout
change the checked-out branch

Merge & rebase

git merge
join two branches with a merge commit
git merge --ff
fast-forward when possible
git rebase
replay commits onto another base

Conflict resolution

<<<<<<< HEAD
start of our side
=======
separator between the two sides
>>>>>>> <branch>
end, their incoming side
git checkout --ours <file>
keep our side
git checkout --theirs <file>
keep their side

Stack branches on main with review

git rebase -i main
on main: todo list opens with only noop, replace it
:r !git log --reverse --format='pick \%h \%s' main..<branch>
in nvim: paste the branch's commits as picks
break
todo line after each branch: pause for review
:DiffviewOpen main
at a break: all stacked changes, right side editable
git commit --amend -a
fold review edits into the last commit
git rebase --continue
go on to the next branch
git rebase --abort
stop and put main back where it started

Remotes & Syncing

Transfer

git clone
copy a remote repository
git remote
manage the set of tracked remotes
git fetch
download remote objects and refs
git pull
fetch and integrate
git push
upload local commits
git push <remote> <local>:<remote-branch>
push to an explicit remote branch
git push -u <remote> <branch>
push and set upstream tracking

Tracking branches

git branch -vv
list branches with upstream and ahead/behind
git branch -r
list remote-tracking branches
git branch -a
list local and remote branches
git branch --set-upstream-to=<remote>/<branch> <local>
set the upstream of a local branch
git branch --unset-upstream
remove the upstream link
git switch -c <local> origin/<remote-branch>
create a local branch tracking a remote branch
git switch -t origin/<branch>
create a tracking branch of the same name

Snippets

# delete all branches except a whitelist
git config --global alias.br-except '!f() { ex=; for b; do ex="$ex --exclude=refs/heads/$b"; done; git for-each-ref --format="%(refname:short)" $ex refs/heads | xargs git branch -d; }; f'

git br-except main                    # keep only main
git br-except main feature-x fix-y    # keep several
git br-except 'feat/*'                # patterns work
