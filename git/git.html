list local branches git branch -v # show pointed commit and ahead/behind status git branch -vv # also show upstream tracking branch git branch # create a branch git switch -c # create a branch and switch to it git switch # switch to a branch git branch -d # delete a branch (only if merged) git branch -D # force-delete a branch (even if not merged) git branch -m old-name new-name # renaming a branch ``` ### Navigation & HEAD ``` git checkout # move HEAD to a commit (detached HEAD state) git checkout # exit detached HEAD by switching to a branch ``` In detached HEAD state you are not on any branch — commits made here are temporary unless you create a branch from them. ### Reset Reset moves the current branch pointer to a target commit: ``` git reset --soft HEAD~n # move branch only; keep changes staged git reset --mixed HEAD~n # move branch; keep changes unstaged (default) git reset --hard HEAD~n # move branch; discard all changes after target commit ``` Discard all local changes and return to last commit: ``` git reset --hard HEAD ``` Squash the last n commits into one: ``` git reset --soft HEAD~n git add . git commit -m "message" git push --force-with-lease # safer than --force: refuses if remote moved unexpectedly ``` ### Stash ``` git stash # stash current tracked changes git stash -u # stash tracked and untracked changes git stash show # summary of latest stash git stash list # list of stashes git stash pop # apply last stash and delete git stash drop stash@{x} # delete stash x git stash clear # delete all stashes git stash show -p # full diff of latest stash git stash show -p stash@{1} # full diff of a specific stash git stash apply stash@{1} # re-apply a stash onto the current working tree git stash drop stash@{1} # remove a stash from the list ``` ## Remote Operations ### Sinking with the server git fetch --prune # must be on the receiving branch ``` - fast-forward: when git can move a branch pointer forward without creating a merge commit (no divergence) git merge -ff Put commits of feature on top of base ``` git switch feature git rebase ``` you can rebase without checkout by git rebase Git will ask you to choose merge/rebase/fast-forward when local and remote have diverged. Stacked PRs — each PR targets the previous branch, not main: ``` git switch chore/my-feature git rebase feature/base-branch ``` PR chain example: ``` main └── logging/structured-logging (base: main) └── feature/separate-deps-jar (base: logging/structured-logging) └── chore/move-scripts (base: feature/separate-deps-jar) ``` ### Worktree A worktree is a second checkout of the same repository in a different directory, sharing the same .git folder. Useful to work on two branches simultaneously. ``` git worktree add # check out an existing branch into a new dir git worktree add -b # create a new branch and check it out git worktree add --detach # detached HEAD at a specific commit git worktree list git worktree remove /path/to/worktree # errors if dirty git worktree remove --force /path/to/worktree # forces removal # list all worktrees ``` ### Submodules In a submodule, HEAD points to a specific commit, not a branch. Update the submodule to the latest commit from its remote: ``` git submodule update --remote --merge git add git commit -m "update submodule to latest commit" ``` ⏺ git push --force-with-lease git commit --amend git rebase -i pick: Keep commit as-is. reword: Keep commit but edit message. edit: Stop to modify the commit content. squash: Combine with previous commit and keep messages. fixup: Combine with previous commit but discard its message. drop: Delete the commit entirely. ## Open Questions - What exactly happens when you delete a branch?
