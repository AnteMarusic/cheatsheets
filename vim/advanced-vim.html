Vim Grammar — compose, don't memorize

The map: categories of Vim commands

Category What it is Examples
Motions move the cursor; also serve as operator targets w } $ f{c} G
Operators act over a motion / text object d y c > = gu gq
Text objects a region (not a motion) for operators / visual iw ip i" it
Standalone commands do something now, take no motion x p r J ~ u . <C-r>
Modifiers counts and registers that prefix the above 3 "a
Modes the state you're in normal, insert, visual (char / line / block), operator-pending, command-line, replace, terminal
Ex commands a separate : command language with ranges :s :g :w :normal

The formula

{op}{motion}
operator acts from the cursor to where the motion lands
{op}{i|a}{object}
operator acts on a whole text object (a region)
{op}{op}
double the operator = act on the whole line (dd)
{count}{op}{count}{target}
counts multiply (2d3w = delete 6 words)

Pick one operator (verb) and one target — a motion (a place) or a text object (a region). Any verb × any target is a valid command. You never memorize di", ci", yi": you build them.

Operators (verbs)

d
delete (cut)
c
change (delete, then insert)
y
yank (copy)
> / <
indent / dedent
=

gu / gU / g~

gq / gw
reflow to textwidth (gw keeps the cursor)
!
filter the lines through an external command
zf

v isn't an operator but composes the same way: it selects the target instead of acting on it (vi").

Inclusive motions include the landing char (de), exclusive ones stop before it (dw). That's the only subtlety when an operator meets a motion.

Compose = verb × target

d + iw
diw delete inner word
c + i"
ci" change inside quotes
y + a(
ya( yank incl. the parentheses
v + it
vit select inside a tag
> + ip
>ip indent the paragraph
gq + ap
gqap reflow the paragraph
d + f;
df; delete up to and incl. the next ;

Swap the verb, keep the target: di" → ci" → yi" → vi". Swap the target, keep the verb: diw → di( → dit.

The "standalone" keys are compositions

x
= dl (delete one char right)
X
= dh (delete one char left)
D
= d$ (delete to end of line)
C
= c$ (change to end of line)
Y
= y$ (yank to end of line)
s
= cl (substitute one char)
S
= cc (substitute the whole line)

Learn the grammar and these fall out for free — they're just common verb+target pairs with a one-key name.
