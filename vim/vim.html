Vim Cheat Sheet

Keyboard key names

<leader>
leader key (mapped to Space)
C
Control (modifier key)
<S>
Shift
<Del>
Delete
<BS>
Backspace
<CR>
Enter / Return
<Tab>
Tab
<C-smth>
notation to say: write control + smth at the same time

Counts: {count}{command}

3dd
repeat: delete 3 lines
2p
repeat: paste twice
2d3w
multiply: 2 × 3 = delete 6 words
5j
repeat a motion: down 5 lines
3ihi<Esc>
repeat inserted text: types hihihi
5G
go to the Nth: jump to line 5 (position, not repeat)
3.
repeat last change 3 times (replaces its original count)

Help

<leader>sk
List all the keymaps and show the file of definition.
:h[elp] keyword
help manual for the keyword

Movements

Within the line

h / l
left / right one character
0
first column of the line
^
first non-blank character
$
end of the line
g_
last non-blank character
fx / tx
jump next inclusive / exclusivex
Fx / Tx
jump previous inclusive / exclusivex
; / ,
repeat last f/t/F/T forward / backward

By word

w / W
start of next word / WORD exclusive(WORD is a sequence of non-blank characters)
e / E
end of next word / WORD inclusive
ge / gE
end of previous word / WORD inclusive
b / B
start of previous word / WORD exclusive

By structure

%
matching pair () {} [] (see :h matchpairs)
} / {
next / previous paragraph (or block, in code)

Scroll

j / k
down / up one real line (prefix a count, e.g. 5j)
gj / gk
down / up one screen line (for wrapped lines)
M
middle of the screen
H / L
previous / next buffer (LazyVim remaps these; default is top / bottom of the screen)
gg / G
first / last line of the file
5gg / 5G
go to line 5
<C-d>/<C-u>
cursor and screen down / up half a page
<C-f>/<C-b>
screen down / up one page
<C-e>/<C-y>
scroll down (extra line) / up one line (cursor stays)

Marks, jumps & history

<C-o>/<C-i>
jump to older / newer position (jump list)
:ju[mps]
list of jumps
g; / g,
older / newer position in the change list
:changes
list of changes
ma
set mark a at the cursor
'a
jump to the line of mark a (`a = exact column)
y'a
yank text up to mark a
:marks
list of marks
''
line before the last jump
'.
line of the last change
'0
line where Vim was last exited
'"
line when last editing this file
<C-]>
jump to the tag under the cursor

Marks & bookmarks (extended)

mx
Set mark x
m,
Set the next available alphabetical (lowercase) mark
m;
Toggle the next available mark at the current line
dmx
Delete mark x
dm-
Delete all marks on the current line
dm<space>
Delete all marks in the current buffer
m]
Move to next mark
m[
Move to previous mark
m:
Preview mark. This will prompt you for a specific mark to preview; press <cr> to preview the next mark.
m[0-9]
Add a bookmark from bookmark group[0-9].
dm[0-9]
Delete all bookmarks from bookmark group[0-9].
m}
Move to the next bookmark having the same type as the bookmark under the cursor. Works across buffers.
m{
Move to the previous bookmark having the same type as the bookmark under the cursor. Works across buffers.
dm=
Delete the bookmark under the cursor.

Code

gd
go to definition
gr
references
gD
declaration

Flash (jump)

s
jump: type chars at the target, then press its label
S
Treesitter: label syntax nodes to select code structurally
r
remote operations: press y to access yank mode, use r to access flash, reach the destination, select with a text object or with a motion and paste at the original position with p
R
same as r but with Treesitter search
<C-s>
toggle flash labels while typing a / search

Folds

<BS>
toggle the fold (function) under the cursor
zd
delete the fold under the cursor (text stays)
zR
open (Reveal) all folds
zM
close (Max) all folds
zr
open (reduce) the folding by one level
zm
close (minimize) the text by one level

Move in snacks

<C-n>
insert (auto-complete) next match before the cursor during insert mode
<C-p>
insert (auto-complete) previous match before the cursor during insert mode

Registers

""
unnamed: last yank or delete (what p uses)
0
last yank only (survives deletes)
1 - 9
delete/change ring, line-wise ("1 newest, older shift down)
-
last small delete (less than one line)
"a - "z
named registers you set yourself
+
*
system clipboards (same as * on macOS)
_
black hole: delete without touching any register
%
current file name (read-only)
.
last inserted text (from the start of insert mode to the end).
:
last command-line command
"/
last search pattern

Accessing Registers

<C-r>x
insert register x in insert/command-line mode
:reg
show all registers and their contents
"
which-key shows a popup previewing every register's content.
synced with the system clipboard by LazyVim's clipboard=unnamedplus (set in config/options.lua).

Editing model: operator + range

op + motion
from the cursor to a target (dw, d$, y2j)
op + i/a + object
the whole text object (diw, ci", ya()
visual then op
select first, then apply the operator (viw then d)
opop
double the operator to act on the whole line (dd, yy, cc, >>)
op
operators: d delete, y yank, c change, >/< indent, = re-indent, gu/gU/g~ case, gq format

Visual mode (select)

Start a selection (differ only in shape)

v
charwise: select by character
V
linewise: select whole lines
<C-v>
blockwise: select a rectangle / column
gv
reselect the last selection
o / O
other end of the selection / other corner (block)
viw / vaw
select inner word / a word
<Esc>/<C-c>
leave visual mode

Act on the selection (same in all three)

y / d / c
yank / delete/change the selection
> / <
indent / unindent
u / U / ~
lowercase / uppercase/toggle case
rc
replace every selected char with c
:
run an Ex command on the selected range ('<,'>)

Block only (<C-v>): edit many lines at once

I
insert at the start of every line, applied on <Esc> (not live cursors)
A
append at the end of every line (use $ first for ragged lines)
$
extend the block to the end of each line

Text objects (i inner/a around)

The objects

iw / aw
word / a word (with surrounding space)
is / as
sentence / a sentence
ip / ap
paragraph / a paragraph
i" / a"
inside quotes / incl. the quotes (' ` too)
i( / a(
inside / incl. parentheses (also b)
i{ / a{
inside / incl. braces (also B)
i[ / i<
inside brackets / angle brackets
it / at
inside / incl. an HTML/XML tag

Copy (yank)

yy
yank (copy) a line
2yy
yank 2 lines
yw
yank from the cursor to the start of the next word
yiw / yaw
yank inner word / a word (incl. surrounding space)
y$ or Y
yank to end of line
"xy
yank into register x ("X appends)

Delete (cut)

dd
delete (cut) a line
2dd
delete 2 lines
dw
delete from the cursor to the start of the next word
diw / daw
delete inner word / a word (incl. surrounding space)
d$ or D
delete to end of line
x
delete the character under the cursor
"_dd
delete without copying (black-hole register)
:3,5d
delete lines 3 to 5
:g/{pattern}/d
delete all lines matching pattern
:g!/{pattern}/d
delete all lines NOT matching pattern

Paste (put)

p / P
put (paste) after / before the cursor
"xp
paste from register x
"0p
paste the last yank (ignores deletes)
gp / gP
paste, then leave the cursor after the new text
]p
paste and adjust indent to the current line
:put
paste on a new line below (linewise), even for charwise text

Replace

rc
replace one character with c
R
Replace mode: overwrite until <Esc>
~
toggle case of the character under the cursor
cw / ciw
change word / inner word
cc / C
change the whole line / to end of line
cl
change one character (same as the default s, which flash remaps)

Search & replace

Search

/pattern / ?pattern
search forward / backward for pattern
n / N
repeat search in the same / opposite direction
* / #
search the word under the cursor forward/backward
\vpat
'very magic': regex chars work without escaping
:noh
clear the search highlighting

Replace (substitute)

:s/old/new//:s/old/new/g
replace first / every match on the current line
:%s/old/new/g
replace every match in the whole file
:%s/old/new/gc
confirm each (y/n/a/q/l)
:'<,'>s/old/new/g
replace only within the visual selection
:%s/old/new/gi
case-insensitive (flag i)
&
repeat the last :s on the current line
<C-r><C-w>
insert the word under the cursor into the command line

Undo / redo

u
undo the last change
<C-r>
redo (reverse the last undo)
U
undo all recent changes on the last-edited line (toggle)
g- / g+
older / newer text state (walks the whole undo tree by time)
:earlier 5m / :later 5m
time-travel to how the file was 5 minutes ago/forward

Diff

]c
jump to start of next hunk
[c
jump to start of
do or :diffg[et]
obtain (get) difference (from other buffer)
dp or :diffpu[t]
put difference (to other buffer)
:diffthis
make current window part of diff
:dif[fupdate]
update differences
:diffo[ff]
switch off diff mode for current window

Insert Mode

i
insert before the cursor
I
insert at the beginning of the line
a
insert (append) after the cursor
A
insert (append) at the end of the line
o
append (open) a new line below the current line
O
append (open) a new line above the current line
<C-w>
delete word before the cursor during insert mode
<C-t>
indent (move right) line one shiftwidth during insert mode
<C-d>
de-indent (move left) line one shiftwidth during insert mode
<C-r>x
insert the contents of register x
<Esc>/<C-c>
exit insert mode

Join, add line in n mode

J
join the line below to the current one with a space
[<space> / [<space>
(normal mode) add line above / below cursor

Macros

qx … q
record a macro into register x; replay with @x, repeat with @@
qa
record macro a
q
stop recording macro
@a
run macro a
@@
rerun last run macro

Indent text

>>
indent (move right) line one shiftwidth
<<
de-indent (move left) line one shiftwidth
>%
indent a block with () or {} (cursor on brace)
<%
de-indent a block with () or {} (cursor on brace)
>ib
indent inner block with ()
>at
indent a block with <> tags
3==
re-indent 3 lines
=%
re-indent a block with () or {} (cursor on brace)
=iB
re-indent inner block with {}
gg=G
re-indent entire buffer
]p
paste and adjust indent to current line

Comment Uncomment

gcc
Toggle comment uncomment a line

Exiting

:w
write (save) the file, but don't exit
:w !sudo tee %
write out the current file using sudo
:wq
write (save) and quit
:q
quit (fails if there are unsaved changes)
:q!
quit and throw away unsaved changes
:wqa
write (save) and quit on all tabs

Buffers, windows, tabs

Buffer
in-memory text of a file, including unsaved changes
Window
a viewport onto a buffer; split one to compare files or keep a reference
Tab
a layout of windows; use one per task or area of the project

Grep

<leader>/
search for pattern in multiple files
<leader>sw
grep word under cursor
<leader>sb
search lines in the current buffer

Tabs

:tabnew or :tabnew {page.words.file}
open a file in a new tab
<C-w>T
move the current split window into its own tab
gt
move to the next tab
gT
move to the previous tab
#gt
move to tab number #
:tabm[ove] #
move current tab to the #th position (indexed from 0)
:tabc[lose]
close the current tab and all its windows
:tabo[nly]
close all tabs except for the current one
:tabdo command
run the command on all tabs (e.g. :tabdo q - closes all opened tabs)

Buffers

<S-h>/<S-l>

<leader>fb

:e[dit] file
edit a file in a new buffer
go to the previous buffer
:bd[elete]

<leader>bd
Delete current buffer

Windows & splits

:vert[ical] ba[ll]

<C-w>s/<C-w>v
split horizontally / vertically
<C-w>q
quit a window
<C-Left>/<C-Right> / <C-Up> / <C-Down>

<C-w>=

<C-w>h/l/j/k
move to the window left / right/down / up
<C-w>H/L/J/K
move the window to the far left / right/bottom / top
