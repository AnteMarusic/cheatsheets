Claude Code cheatsheet

Explain the context structure of claude Explain what is the sidecar chat
context window
loaded at startup: system prompt, output style, CLAUDE.md, auto memory, MCP tool names, skill descriptions. Added while working: your messages, Claude's replies, file reads, tool results, path rules, hook output. A subagent has its own context window; only its summary comes back.
side chat
a question or task that runs beside the main chat. /btw sees the full conversation but has no tools, and its answer never enters the history. A fork copies the conversation into a background subagent that has tools.
/resume
resume a chat (it shows the list with the names)
/rename [name]
overwrites the automatic name that claude gives to the chat
/branch [name]
creates a new chat with the same context as the current and give optional name
/fork
creates a new sidecar chat that has the same context as the current and will report the result to the current after each message.
/btw <question>
ask a question in a sidechar chat that has the same context as the current but will not report the result to the current. The
/branch [name]
creates a new chat with the same context as the current and give optional name
/rewind
(or Esc Esc) pick a past prompt, then: restore code and conversation, restore conversation only, restore code only, summarize from here, or summarize up to here. There is no undo operation for rewind (if you want to jump back to the old state, before rewinding perform a branch).
/context [all]
show context usage
/cost
alias for /usage: plan usage level, can set claude config from here too
/simplify [target]
agent that review code for reuse, simplification, efficiency and abstraction level, then apply fixes; does not look for bugs

Agent view (background sessions)

claude agents
open agent view: list and dispatch background sessions
claude agents --json [--all]
print active sessions as JSON and exit; --all adds completed ones
claude agents --cwd <path>
show only sessions started under path
claude agents --model / --effort / --permission-mode
defaults for sessions dispatched from agent view
claude --bg "prompt"
start a session in the background and print its id
claude attach <id|name>
open a background session in this terminal
claude logs <id|name>
print recent terminal output of a session
claude stop <id>
stop a session; the conversation is kept
claude rm <id>
delete a session and its worktree when safe
claude respawn [id | --all]
restart sessions on the current Claude Code version
