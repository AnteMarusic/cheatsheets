Claude Code cheatsheet

Sessions

Resume

/resume [session]
resume a conversation by ID or name, or open the session picker; alias /continue
claude -c
continue the most recent conversation in this directory
claude -r [id|name]
resume a session by ID or name, or open the picker

Rename

/rename [name]
rename the session; without a name, generate one from the history
claude -n <name>
set the session name at startup

Branch

/branch [name]
copy the conversation at this point and switch into the copy; return to the original with /resume
claude -c --fork-session
continue the last session under a new session ID

Undo

Rewind

/rewind
open the rewind menu; aliases /checkpoint, /undo
Esc Esc
open the rewind menu when the prompt is empty
Restore code and conversation
revert files and conversation to the selected prompt
Restore conversation
rewind the conversation, keep the current files
Restore code
revert files, keep the conversation
Summarize from here
compress messages after this point into a summary
Summarize up to here
compress messages before this point, keep later ones

Rewind does not restore files changed only by Bash commands. Use git for those.

Info

/context [all]
show context usage as a colored grid; all expands the per-item list
/cost
alias for /usage: session cost, plan limits, activity stats
/btw [question]
ask a side question without adding it to the conversation; without a question, show the last one

Skills

/simplify [target]
review changed code for reuse, simplification, efficiency and abstraction level, then apply fixes; does not look for bugs (use /code-review)
