Java

Files

Read and write (java.nio.file)

Path.of("dir", "a.txt")
build a path from parts
Files.readString(path)
whole file as one String, UTF-8 (Java 11+)
Files.readAllLines(path)
whole file as List<String>, UTF-8
Files.lines(path)
lazy Stream<String>, UTF-8; keeps the file open until closed
Files.writeString(path, text)
creates the file, or truncates it if it exists (Java 11+)
Files.write(path, lines)
write an Iterable of lines; same create/truncate default
StandardOpenOption.APPEND
pass as last argument to append instead of truncating

Manage files

Files.exists(path)
true if the file exists; the result can be outdated right away
Files.createDirectories(dir)
create dir and missing parents; no error if dir already exists
Files.copy(src, dst)
fails if dst exists; add StandardCopyOption.REPLACE_EXISTING to overwrite
Files.move(src, dst)
same rule as copy for an existing dst
Files.delete(path)
throws NoSuchFileException if the file is missing
Files.deleteIfExists(path)
returns false if the file is missing
Files.list(dir)
Stream<Path> of direct entries
Files.walk(dir)
Stream<Path> of all entries, recursive

Examples

Path p = Path.of("notes.txt");

Files.writeString(p, "hello\n");
Files.writeString(p, "world\n", StandardOpenOption.APPEND);
String all = Files.readString(p);  // "hello\nworld\n"

// lines, list, walk hold the file open: close with try-with-resources
try (Stream<String> lines = Files.lines(p)) {
    long n = lines.filter(l -> !l.isBlank()).count();  // 2
}

Streams

Intermediate operations

filter(predicate)
keep elements where the predicate returns true
map(function)
transform each element into one new element
flatMap(function)
transform each element into a stream, then merge all streams into one

Examples

List<String> names = List.of("ann", "bob", "carla");

names.stream()
    .filter(n -> n.length() > 3)
    .toList();                    // [carla]

names.stream()
    .map(String::toUpperCase)
    .toList();                    // [ANN, BOB, CARLA]

List<List<Integer>> nested = List.of(List.of(1, 2), List.of(3));
nested.stream()
    .flatMap(List::stream)
    .toList();                    // [1, 2, 3]

Notes

lazy
intermediate operations run only when a terminal operation (toList, forEach, collect) runs
single use
a stream can be consumed once; create a new one to iterate again
map vs flatMap
map on a List<List<T>> gives Stream<List<T>>; flatMap gives Stream<T>
toList()
Java 16+, returns an unmodifiable list; use collect(Collectors.toList()) on older versions

Strings

endsWith

s.endsWith(<suffix>)
true if s ends with suffix
"report.pdf".endsWith(".pdf")
true
"report.PDF".endsWith(".pdf")
false: the match is case-sensitive
s.toLowerCase().endsWith(".pdf")
case-insensitive check
"abc".endsWith("")
true: every string ends with the empty string
"abc".endsWith(null)
throws NullPointerException
