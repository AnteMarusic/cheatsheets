Streams

Intermediate operations

filter(predicate)
keep elements where the predicate returns true
map(function)
transform each element into one new element
flatMap(function)
transform each element into a stream, then merge all streams into one

Examples

List<String> names = List.of("ann", "bob", "carla");

names.stream()
    .filter(n -> n.length() > 3)
    .toList();                    // [carla]

names.stream()
    .map(String::toUpperCase)
    .toList();                    // [ANN, BOB, CARLA]

List<List<Integer>> nested = List.of(List.of(1, 2), List.of(3));
nested.stream()
    .flatMap(List::stream)
    .toList();                    // [1, 2, 3]

Notes

lazy
intermediate operations run only when a terminal operation (toList, forEach, collect) runs
single use
a stream can be consumed once; create a new one to iterate again
map vs flatMap
map on a List<List<T>> gives Stream<List<T>>; flatMap gives Stream<T>
toList()
Java 16+, returns an unmodifiable list; use collect(Collectors.toList()) on older versions
