# Cheatsheets

Styled HTML reference pages for tmux and vim.

Run this in the repo root to open a live server on localhost that displays the cheat-sheets:

```bash
npx live-server
```

Optionally open a specific cheat-sheet directly:

```bash
npx live-server --open=tmux/tmuxcheat.html
```

## Available cheat-sheets

- `tmux/tmuxcheat.html`
- `vim/vim.html`
