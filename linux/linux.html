Linux cheatsheet

Shell

exit
kill the terminal
man <tool>
manual of a tool
$<name>
expand a variable
'...'
single quotes: literal, no expansion
"..."
double quotes: expand variables
<(...)
process substitution: command output seen as a file
tty
print the terminal name

Files & search

List & size

ls -la
list all files with details
du -sh
summarized size of a folder

Find

find . -name "name"
find by exact name
find . -name "*partialname*"
find by partial name
rg --files | rg name
list files then filter by name
xargs
build commands from stdin

Search & text

rg / grep
search file contents
sed
stream editor
awk
text processing language
lex
lexical analyzer generator
yacc
parser generator

Processes & monitoring

pgrep
find process IDs by name
ps
list processes
top
live process monitor
lsof
list open files
fs_usage
report filesystem activity (macOS)
sample
profile a running process (macOS)
spindump
capture stack samples (macOS)
lldb bt
backtrace in the debugger

Remote & transfer

Sync & copy

rsync -avz -e 'ssh -p 8120' <user>@<host>:<src> <dst>
sync folders, resume interrupted transfers, skip unchanged files
ftp -b <batchfile>
run ftp commands from a batch file
sshfs
mount a remote filesystem over ssh
telnet
plain-text remote connection
pread
read from a file descriptor at an offset

rsync options

-a
archive (recursive, preserve metadata)
-v
verbose
-z
compress during transfer
-e <shell>
specify the remote shell

Clipboard over SSH

ssh -X
X11 forwarding: remote Vim's "+ talks to your local X server (needs XQuartz on Mac)
OSC 52
terminals + Vim push a copy to your local clipboard via an escape sequence; works over SSH
