Tmux cheatsheet

<prefix>: ctrl b

Sessions

Create

Tmux
Tmux new
<prefix>:new

Options

-s <name>

Kill

Tmux kill-session
kill last session

Options

-a
all but the current
-t <name>
kill session name
-at <name>
kill all but session name

Attach session

tmux a
attach last session

Options

-t <name>
attach session name

List sessions

tmux ls
<prefix>s

Manage

<prefix> d
detach from the session
<prefix> $
rename the current session
<prefix> w
list sessions and windows (choose-tree)
<prefix> (
switch to the previous session
<prefix> )
switch to the next session

Windows

Manage

<prefix> c
create a new window
<prefix> ,
rename the current window
<prefix> &
kill the current window
<prefix> l
last (previously active) window
<prefix> w
list and choose a window
<prefix> 1..9
select window by number
<prefix> p
previous window
<prefix> n
next window
<prefix> :
open the command prompt
<prefix> :movew -r
renumber windows to close gaps

Panes

Navigate

Ctrl h/j/k/l
move between panes
<prefix> ;
last active pane

Split & manage

<prefix> %
split into left/right panes
<prefix> "
split into top/bottom panes
<prefix> z
toggle pane zoom
<prefix> !
break pane into a new window
<prefix> x
kill the pane
<prefix> H/J/K/L
resize left/down/up/right by 5 (custom binding)
<prefix> :join-pane -s <src> -t <dst>
move a pane into another window

Copy & paste

Copy mode

<prefix> [
enter copy mode
<prefix> ]
paste the buffer
q
quit copy mode

Selection (vi keys)

Space
start selection
v
toggle rectangle/block selection
Enter
copy selection and exit
Escape
clear the selection

Search

/
search forward
?
search backward
n / N
next/previous match

Buffers

<prefix> =
list buffers and choose one to paste
tmux list-buffers
list buffers from the shell
tmux save-buffer <file>
save the buffer to a file

Delete buffer

tmux delete-buffer
delete the most recent buffer

Options

-b <name>
delete buffer name
